# Guard

Propose each, apply on the person's yes:

- **The finder in CI**, failing on new findings only: the current findings become its baseline, and the baseline only falls.
- **The done-rule** for work that replaces a path: the replacement is not done until the old path is deleted in the same change. Proposed as a convention through the `write-conventions` skill, and as a line in the run's definition of done when the work runs under the `orchestrate` skill.
- **Boundary tests** where a module's single entry point is not yet enforced: dead code behind one entry stays local, and its removal stays cheap.
