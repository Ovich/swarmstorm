# The brief

**A brief says where the work is and what the charter asks; nothing else.** Never the kind's
document, never the design, the criteria or the seams (the member's document carries them),
never encouragement. The kind's skill holds its templates.

**The last line** only when the member has a boundary the charter does not draw: a directory it
must not touch, a command it must not run, an environment it must not reach. The watch's
`--forbidden` pattern is built from that sentence.
